# ALVB - 상업공간 인테리어 디자인

Next.js 기반의 상업공간 인테리어 디자인 회사 웹사이트입니다.

## 주요 기능

- **홈페이지**: 회사 소개 및 주요 서비스 안내
- **회사소개**: 회사 철학, 핵심 가치, 작업 프로세스 소개
- **레퍼런스**: 완료된 프로젝트 포트폴리오 (카테고리별 필터링)
- **온라인 견적**: 프로젝트 정보 입력 및 미팅 일정 예약

## 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI**: React 18

## 시작하기

### 1. 패키지 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 결과를 확인하세요.

### 3. 빌드

```bash
npm run build
```

### 4. 프로덕션 실행

```bash
npm start
```

## 프로젝트 구조

```
ALVB/
├── app/                    # Next.js App Router
│   ├── page.tsx           # 홈페이지
│   ├── about/             # 회사소개
│   ├── portfolio/         # 레퍼런스
│   ├── quote/             # 온라인 견적

│   └── globals.css        # 글로벌 스타일
├── components/            # 재사용 컴포넌트

│   └── Footer.tsx        # 푸터
├── public/               # 정적 파일
└── package.json
```

## 디자인 특징

- 젊고 세련된 UI/UX
- 깔끔한 레이아웃과 타이포그래피
- 반응형 디자인 (모바일, 태블릿, 데스크톱)
- 부드러운 애니메이션과 인터랙션
- Primary Color: 블루 계열 (#0ea5e9)

## 페이지별 설명

### 홈페이지 (`/`)
- Hero 섹션: 메인 메시지와 CTA 버튼
- 특징 섹션: 혁신적 디자인, 빠른 시공, 합리적 가격
- 통계 섹션: 프로젝트 수, 고객 만족도 등

### 회사소개 (`/about`)
- 회사 철학 및 비전
- 핵심 가치 (창의성, 효율성, 신뢰)
- 작업 프로세스 (상담 → 기획 → 디자인 → 시공)
- 전문가 팀 소개

### 레퍼런스 (`/portfolio`)
- 프로젝트 포트폴리오 그리드
- 카테고리별 필터링 (카페, 레스토랑, 리테일, 오피스, 뷰티)
- 프로젝트 상세 정보 (위치, 평수, 연도)

### 온라인 견적 (`/quote`)
- 연락처 정보 입력
- 프로젝트 정보 (업종, 인테리어 범위, 평수, 예산, 위치)
- 미팅 희망 일정 선택
- 추가 요청사항 입력

## 커스터마이징

### 색상 변경
`tailwind.config.ts` 파일에서 primary 색상을 변경할 수 있습니다.

### 컨텐츠 수정
각 페이지의 `.tsx` 파일에서 텍스트와 이미지를 수정할 수 있습니다.

### 레퍼런스 프로젝트 추가
`app/portfolio/page.tsx`의 `projects` 배열에 새로운 프로젝트를 추가하세요.
